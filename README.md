# Adaptive Reading Tool for ESL Learners

An intelligent text simplification tool designed for adult ESL learners with reading difficulties. Features personalized visual settings, adaptive complexity levels, and built-in comprehension tracking.

## 🎯 Project Purpose

Many adult ESL learners face reading challenges due to:
- Unfamiliar vocabulary and complex sentence structures
- Visual processing difficulties (small fonts, dense text)
- Working memory limitations during comprehension
- Lack of immediate feedback on understanding

This tool addresses these challenges through **adaptive text simplification** and **personalization features** that respect cognitive diversity in language learning.

## ✨ Features

### 📝 Text Simplification
- **Three complexity levels**: Beginner (A1-A2), Intermediate (B1), Advanced (B2+)
- **Intelligent vocabulary replacement**: Context-aware substitution of complex words
- **Sentence restructuring**: Breaks down long, complex sentences for beginner learners
- **Real-time complexity analysis**: Shows before/after difficulty scores

### 👁️ Visual Customization
- **Adjustable font size** (12-24px)
- **Flexible line spacing** (1.2-2.5)
- **Customizable text width** for optimal reading comfort
- **Persistent settings** - saves your preferences locally

### 📚 Learning Support
- **Word highlighting**: Complex vocabulary highlighted with hover definitions
- **Comprehension quizzes**: Auto-generated questions to check understanding
- **Progress tracking**: Monitor texts simplified and comprehension scores
- **Adaptive feedback**: System learns from your performance over time

## 🔬 Theoretical Foundation

This tool is based on:

**Cognitive Load Theory** (Sweller)
- Minimizes extraneous cognitive load through visual customization
- Manages intrinsic load through adaptive complexity
- Supports germane load through comprehension checks

**Usage-Based SLA** (Ellis)
- Provides comprehensible input at appropriate levels
- Allows repeated exposure to simplified patterns
- Supports statistical learning through examples

**Universal Design for Learning** (CAST)
- Multiple means of representation (visual customization)
- Multiple means of engagement (personalized difficulty)
- Multiple means of action/expression (progress tracking)

## 🛠️ Technical Implementation

### Architecture
- **Single-page application**: No server required, runs entirely in browser
- **Client-side processing**: All simplification happens locally for privacy
- **Local storage**: Saves preferences and progress on your device
- **Responsive design**: Works on desktop, tablet, and mobile

### Text Analysis
- **Complexity scoring**: Based on word length, sentence length, and vocabulary frequency
- **Pattern recognition**: Identifies complex structures for simplification
- **Context preservation**: Maintains meaning while reducing complexity

### Simplification Strategies
1. **Vocabulary substitution**: Replaces complex words with simpler synonyms
2. **Sentence splitting**: Breaks long sentences at natural boundaries
3. **Structure simplification**: Converts passive voice and complex constructions
4. **Coherence markers**: Adds explicit transitions for clarity
